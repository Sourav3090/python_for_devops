Netwok for DevOps:

Netwok:
    -Netwok is an Infrastructure of two or more devices connected to 
     each other for data and resources sharing. like(router, modem, nic, buses, cables)
Networking:
    -Networking is the process of designing, implementing and managing communication between 
     those connected devices.

Protocol:
    -A protocol is a set of rules that defines how data is performed, transmitted and received 
     between devices/server.
    -Its follow format in order: 1.Syntax 2.Symantics 3.Timing.

     *Protocol Categories:
        1.Communication Protocols:
            -Defines how data travels. TCP,UDP,ARP,FTP,SMTP.

        2.Network Protocols:
            -Defines encryption and authentication: TLS, SSL, SSH, IPsec.
        
        3.Management Protocols:
            -Define network config and monitoring: DHCP, DNS, NTP, SNMP.

Q.What is EC2 ?
=>  1. EC2 stands for Elastic Compute Cloud.
    2. It is AWS Virtual Server which have compute power.
    3. You can launch a server in minutes, use it , shutdown it without purchasing and managing physical H/W.
    4. Billing is based on usage (Pay as you go) per hour/ per second depending on the instance type and OS.

Q.Amazon Machine Image(AMI)
=>  -AMI is a pre-build tamplate that contains OS, software and server configuration.
    -Every EC2 instance is created from an AMI.
    -You can create a custome AMI from a configured instance called a "Golden Image" used and launch 
     a pre-configured EC2 instance.
    -Available Options on AWS : Quick start AMI(46), My AMI, AWS Marketplace AMIs(7125), Community AMI(500) 

Q.Instance ?
=>  [family] [generation]. [size]
    1. Determines the H/W profile vCPU(Virtual), RAM and network.
    2. t3 = General Purpose (Developmemt, Testing, Learning Purpose, low-traffic apps).
    3. c5 = Compute Engine (ML mode training, batch-processing)
    4. r5 = Memory Optimized.
    5. m5 = balanced compute.

Q.Purchasing Option.
=>  1.On-Demand(DI): pay per hour/second, no upfront cost,
    2.Reserved Instance(RI): Commit 1 or 3 year, up 72% cheaper, best for steady.
    3.Spot Instance(SIs): 90% cheaper, Use unused compute instance but aws can 
     terminate with 2-minutes notice.
    4.Dedicated Host : A physical server dedicated to your account for software licences
      (HIPAA, PCI-DSS)
Q. Key Pair:
=>  1. For Accesing Remotely.

Q. Security Groups.
=>  1.Acts as a virtual firewall at the instance level.
    2.Controls inbound and oubound traffic using rules.
    3.Stateful : if inbound traffic is allow the response is automatically permitted.
      (rule only allow, cannot deny) 
    4.Multiple SG (Security Group) can be attached to one instance.
