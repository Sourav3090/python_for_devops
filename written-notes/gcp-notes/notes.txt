Q. What is VPC(Virtual Private Cloud) ?
    -A VPC is a Virtual Private Network inside cloud where your cloud 
    resources communicate securely.
    -like a private office network inside a company.
Q. What is Subnet ?
    -A subnet is a smaller division of a VPC Network.
    -Large Network are division into smaller part of:
    1. security
    2.better management
    3.performance
     Types of subnet:
     1. Public 
        *What is public subnet?: 
        -A subnet where server can directly communicate with internet.
     2. Private:
        *What is private Network ?:
        -A subnet where resources are not directly accessible from the 
        internet.
        *Why we use private subnet ?:
        -beacuse sensitive resources should remain hidden.
        -Ex. datatbases, backend API, Interneal Applications
Q. What is Firewall Rules?
    -Firewalls Rules Control:- 
        -Who can access Your VM, Which ports are allowed, which traffic 
        should be block
Q. What is Routes?
    -Route decide where traffic should go.
Q. What is Load Balancer?
    -Load Balancer distribute traffic across multiple servers.
    -Benefits of Load Balancer:
        1. High availability-(if one server fails automatically other work)
        2. Better performmance-(traffic divided)
        3. Scalability-(Easy to add servers)
Q. Difference between Public and Private Subnets
    Public:
        -Internet Accessible
        -Used for web apps
    Private:
        -No direct internet access
        -Used for databases

To install the Google Cloud CLI (GCP CLI) on Ubuntu, follow these simple steps.

The official tool is called the Google Cloud CLI (`gcloud`).

## Step 1: Update Packages

```bash
sudo apt update
```

---

## Step 2: Install Required Packages

```bash
sudo apt install apt-transport-https ca-certificates gnupg curl -y
```

---

## Step 3: Add Google Cloud Repository Key

```bash
curl https://packages.cloud.google.com/apt/doc/apt-key.gpg | sudo gpg --dearmor -o /usr/share/keyrings/cloud.google.gpg
```

---

## Step 4: Add the Google Cloud CLI Repository

```bash
echo "deb [signed-by=/usr/share/keyrings/cloud.google.gpg] https://packages.cloud.google.com/apt cloud-sdk main" | sudo tee /etc/apt/sources.list.d/google-cloud-sdk.list
```

---

## Step 5: Update Again

```bash
sudo apt update
```

---

## Step 6: Install Google Cloud CLI

```bash
sudo apt install google-cloud-cli -y
```

---

## Step 7: Verify Installation

```bash
gcloud version
```

If installed correctly, you will see version details.

---

## Step 8: Login to Your Google Account

```bash
gcloud init
```

This command:

* Opens browser login
* Lets you choose your Google account
* Selects your GCP project

---

## Useful Commands

### Check current account

```bash
gcloud auth list
```

### List projects

```bash
gcloud projects list
```

### Set a project

```bash
gcloud config set project PROJECT_ID
```
